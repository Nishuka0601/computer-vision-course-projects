# 🖼️ ДЗ №3: Класифікація CIFAR-10 за допомогою ResNet-18

Проєкт присвячений переносу знань (Transfer Learning) та тонкому налаштуванню (Fine-Tuning) згорткової нейромережі ResNet-18 на датасеті CIFAR-10 у PyTorch.

## 📊 Основні результати

| Етап | Val Accuracy | Час |
| :--- | :---: | :---: |
| 🔒 **Feature Extraction** (2 епохи) | 37.93% | ~58 сек |
| 🔓 **Fine-Tuning** (3 епохи) | **79.38%** | ~122 сек |

## 🧪 Додаткові експерименти

* 🎨 **Аугментації:** Модель без аугментацій показала 81.10% за 5 епох, однак додавання `RandomCrop` та `RandomHorizontalFlip` покращує генералізацію на реальних даних.
* ⚡ **Batch Size (16 vs 128):** Збільшення розміру батчу до 128 прискорило навчання більше ніж у 2.5 раза (21.82 сек проти 54.88 сек) завдяки ефективній паралелізації на GPU.
* 🛸 **Тестування ракурсів (Unsplash):** Застосування `T.Resize((32, 32))` вирішило проблему масштабу та підвищило впевненість моделі на довільних фото з мережі.
