# Урок 1: Вступ до Computer Vision та бази OpenCV

Практична робота, присвячена знайомству з бібліотекою **OpenCV** та базовим операціям маніпуляції з зображеннями в Python.

## 🎯 Що було реалізовано:
- **Завантаження та збереження:** `cv2.imread()`, `cv2.imwrite()`.
- **Колірні простори:** Конвертація BGR $\rightarrow$ RGB (для корректного відображення в Matplotlib) та BGR $\rightarrow$ Grayscale (`cv2.COLOR_BGR2GRAY`).
- **Геометричні трансформації:**
  - Кадрування (Cropping) за допомогою зрізів NumPy масивів (`img[y1:y2, x1:x2]`).
  - Ресайзинг (`cv2.resize`) зі збереженням пропорцій.
