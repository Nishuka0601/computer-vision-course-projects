## 🎯 Результати роботи пайплайну

### 1. Основне завдання
Для стабільного підрахунку монет застосовано наступний пайплайн:
1. **Нормалізація:** `resize` до ширини 800px (стандартизація масштабу площ).
2. **Фільтрація:** `GaussianBlur(5, 5)` для приглушення внутрішньої чеканки.
3. **Детекція меж:** `Canny(30, 100)` для виявлення малоконтрастних сріблястих монет.
4. **Морфологія:** `MORPH_CLOSE` з ядром `5x5` для склеювання розривів у контурах.
5. **Фільтрація за площею:** `min_area = 250 px²` для видалення дрібного шуму.

> **Підсумок:** Пайплайн правильно знайшов та розмітив **5 з 5 монет (100% точність)** за допомогою `cv2.minEnclosingCircle`.

---

### 2. Додаткова практика
* **`GaussianBlur` `(3,3)` vs `(21,21)`:** Мале ядро викликає надлишок внутрішнього шуму від чеканки, а занадто велике — повністю розмиває та рве контури.
* **`THRESH_OTSU` vs `adaptiveThreshold`:** Оцу зрізає контури через тіні (глобальний поріг), тоді як адаптивний поріг чудово проявляє об'єкти за нерівномірного освітлення.
* **`MORPH_OPEN` vs `MORPH_CLOSE`:** Операція `MORPH_OPEN` знищує тонкі лінії Canny, а `MORPH_CLOSE` гарантовано затягує розриви.
